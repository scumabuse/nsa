# Orbit Health

Русскоязычный прототип для NASA Space Apps Challenge 2026. Задача экипажа — заметить изменения самочувствия, проверить условия измерения и передать бортмедику понятную историю даже при задержке связи с Землёй.

## Запуск

Откройте `dist/index.html` в браузере или запустите локальный сервер из каталога проекта. Для проверки работы без сети используйте сервер.

```powershell
python -m http.server 8787 --bind 127.0.0.1 --directory dist
```

Адрес локального сервера — `http://127.0.0.1:8787/`. После первой загрузки дождитесь надписи «Журнал доступен без сети».

## Сценарий демонстрации

1. На обзоре откройте график сна. Последний учебный замер показывает, как прототип выделяет изменение и предлагает следующий шаг.
2. Переключитесь в личный журнал и добавьте измерение. Для глюкозы укажите связь с приёмом пищи. Для серьёзных симптомов есть отдельная отметка с инструкцией связаться с бортмедиком.
3. В журнале найдите запись, отредактируйте её и скачайте JSON. Сводка содержит все записи текущего режима и статусы последних измерений.
4. В справочнике откройте инструкции по измерениям и пять рисков полёта. [NASA Human Research Program](https://www.nasa.gov/hrp/hazards/)

## Правила прототипа

- Демо и личные записи хранятся отдельно в браузере. Начальные записи в демо синтетические. Очистка данных сайта удаляет журнал.
- Личное сравнение использует медиану дневных медиан как минимум за три предыдущих дня в пределах 30 дней. Для глюкозы контекст должен совпадать. Для показателя старше 48 часов интерфейс предлагает обновить измерение.
- Диапазоны демо, пороги изменений и окно свежести выбраны для хакатонного прототипа. Для применения в миссии потребуются клиническая валидация, бортовые регламенты и защищённое хранение. Сводка скачивается для передачи вручную.

## Проверки

```powershell
node --test tests/model.test.cjs
```

Для сквозного теста нужен Playwright. Укажите `ORBIT_PLAYWRIGHT`, если пакет установлен отдельно, и `ORBIT_BROWSER`, если используется локальный Chrome или Edge. Запустите сервер и выполните `node tests/browser.test.cjs`.
